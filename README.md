# Portfolio — Alpha Yaya Ouattara

Portfolio statique publié par GitHub Pages depuis la racine de la branche `main` du dépôt `chenprof5-commits.github.io`.

## Aperçu local

```sh
python -m http.server 8765
```

Ouvrir ensuite `http://127.0.0.1:8765/`.

Le site utilise `index.html`, `style.css`, `script.js` et le CV PDF placé à la racine. Aucun build ni dépendance JavaScript n'est nécessaire. Les polices chargées depuis Google Fonts disposent de polices de remplacement locales.
